Dustline: a complete open-world crime game in the browser — a sun-baked desert highway city to explore on foot and by car, with traffic, pedestrians, car theft, police chases, missions and a story. Built with three.js, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static file server and open `index.html`.
